## Featured Projects

### 1. Playlytics — Gaming Product Analytics & Player Engagement

[**View GitHub Repository →**](https://github.com/meharr22/playlytics)

**Business context:** Gaming businesses need to understand player behaviour, engagement, monetisation, and churn risk to make informed product and growth decisions.

**What the project covers**
- Developed a Power BI dashboard to explore player behaviour, engagement patterns, monetisation performance, and churn risk.
- Worked with KPIs including Daily Active Users (DAU), Monthly Active Users (MAU), Average Revenue per User (ARPU), total revenue, gameplay hours, and retention metrics.
- Used Power Query for data preparation and DAX for measures and time-based analysis.
- Explored user overview, engagement patterns, monetisation performance, and churn/retention risk.

**Tools & methods:** Power BI, DAX, Power Query, data cleaning, data transformation, data modelling, KPI design.

**Business value:** Helps stakeholders investigate questions such as which game modes are popular, how users engage, what drives revenue, and where re-engagement opportunities may exist.

### 2. ChurnLens AI — Customer Churn Prediction & Retention Analytics

[**View GitHub Repository →**](https://github.com/meharr22/ChurnLens-Predictive-Customer-Churn-Analytics-)

**Business context:** Customer churn affects recurring revenue. Businesses need to identify customers at risk of leaving, understand churn drivers, and prioritise retention actions.

**What the project covers**
- Analysed customer churn patterns and potential drivers.
- Built a machine-learning workflow covering data cleaning, feature engineering, exploratory analysis, model training, evaluation, and prediction generation.
- Developed churn probability scoring and customer risk segmentation.
- Included retention recommendations and Power BI dashboards for churn analysis, churn reasons, and prediction insights.
- Examined patterns associated with contract type, service usage, tenure, payment behaviour, and customer experience.

**Tools & methods:** Python, Pandas, NumPy, Scikit-learn, SQL, Power BI, Joblib, Jupyter Notebook, machine learning.

**Business value:** Supports data-informed retention planning by highlighting at-risk customer groups, churn patterns, and potential actions for further investigation.

### 3. PitchVision — Cricket Performance Analytics Platform

[**View GitHub Repository →**](https://github.com/meharr22/PitchVision-Cricket-Performance-Analytics-Platform)

**Business context:** Team and player evaluation benefits from consistent performance metrics rather than relying only on subjective assessment.

**What the project covers**
- Collected T20 World Cup 2022 data through web scraping.
- Extracted match, batting, bowling, and player information.
- Cleaned and transformed raw JSON data using Python.
- Prepared fact and dimension tables for analysis.
- Built an interactive Power BI dashboard to explore player and team performance.

**Tools & methods:** JavaScript, web scraping, ESPNcricinfo data, Python, Pandas, Jupyter Notebook, JSON, data modelling, Power BI, DAX.

**Business value:** Enables structured comparison of players and teams using measures such as runs, batting average, strike rate, wickets, economy rate, match results, and win/loss trends.
